Add Stepper Studio at `/studio`: configure a flow (steps, sixteen field types from text and selects to date pickers, sliders and one-time codes, layout, form library, validation library and behavior, all on shadcn/ui), choose where the current step lives (a component, search params or one route per step) for Next.js, TanStack Start, React Router or Vite, preview it live on `@stepperize/react`, and install the generated code with the shadcn CLI from a dynamic registry item at `/r/studio/<config>.json`.
