---
title: Primitives
description: Props and snippets of every Stepper component.
---

All primitives pass `class`, `style` and every other attribute to the element
they render. All except `Root` accept a `child` snippet to
[use your own element](/docs/v9/svelte/guides/primitives#rendering-your-own-element).

## Root

Renders a `div`. Creates the flow and provides it.

| Prop | Type | Description |
| --- | --- | --- |
| Every [option](/docs/v9/react/api/options) | | `linear`, `next`, `guard`, `snapshot`, `step`, `onChange`, `onFinish`, `onInvalidStep`. |
| `orientation` | `"horizontal" \| "vertical"` | Default `"horizontal"`. |
| `children` | `Snippet<[stepper]>` | Receives the stepper. Reactive: it only updates for what it reads. |

`onChange` is the flow's callback; the DOM event is `onchange`.

The element has `role="group"` and the name "Stepper"; pass `aria-label` or
`aria-labelledby` to describe your flow. While an async check or `onFinish`
runs it has `aria-busy` and `data-pending`; once the flow has finished it has
`data-finished`.

## List

Renders an `ol`.

| Prop | Type | Description |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | Defaults to the root's. |
| `item` | `Snippet<[step, index]>` | Rendered once per step; items inside it need no `step` prop. |
| `children` | `Snippet` | Used when there is no `item` snippet: write the items yourself. |

## Item

Renders an `li`.

| Prop | Type | Description |
| --- | --- | --- |
| `step` | Step id | Required outside the `item` snippet of a `List`. |
| `children` | `Snippet<[item]>` | Receives the [item](#useitem). |

## Trigger

Renders a `button` that calls `goTo` for its step. Must be inside an `Item`,
and should be inside a `List`.

It is disabled when `linear` does not allow reaching the step, or when you pass
`disabled`. In a flow that is not linear it is a `tab`; in a linear flow it is
a plain button, with `aria-current="step"` on the current one.

## Title and Description

Render a `span` with the step's `title` or `description` field. Children
replace it.

## Indicator

Renders a `span` with `aria-hidden`. Empty by default: style it, or pass
children.

## Content

Renders a `div` while its step is current. It is the `tabpanel` of its trigger
in a flow rendered as tabs, and otherwise a `group` named after the step's
`title`.

| Prop | Type | Description |
| --- | --- | --- |
| `step` | Step id | Required. |
| `forceMount` | `boolean` | Keep it mounted and `hidden` while its step is not current. |

## Prev and Next

Render a `button`.

- `Next` calls `next()` with no argument, which validates the data stored for
  the current step. On the last step it finishes the flow; it is never
  disabled for being at the end.
- `Prev` calls `prev()`, and is disabled when there is nowhere to go back to.

While an async check or `onFinish` runs, both are `aria-disabled` and ignore
clicks, and have `data-pending`.

Once the flow has finished, `Next` is `aria-disabled` with `data-disabled` and
ignores clicks, so the flow is not submitted twice. It becomes available again
when the flow changes.

Your own `onclick` runs first. Call `event.preventDefault()` in it to handle
the move yourself.

## The child snippet

```ts
child?: Snippet<[{ props: Record<string, unknown> }]>
```

When present it is rendered instead of the default element, and `children` is
ignored. Spread `props` onto exactly one element.

## useItem

`Stepper.useItem()` returns the enclosing item as a reactive object. Call it
while the component initialises.

| Field | Type | Description |
| --- | --- | --- |
| `step` | `Step` | The step, with all its fields. |
| `index` | `number` | Its position. |
| `state` | `"pending" \| "current" \| "complete"` | |
| `invalid` | `boolean` | Its last validation failed and its data has not changed since. |
| `disabled` | `boolean` | `goTo` would be refused right now. |
| `pending` | `boolean` | A move is running. Every step is `disabled` meanwhile. |

Outside an `Item` it throws [SZ101](/docs/v9/core/errors#sz101).

## Diagnostics

In development the primitives warn about a `child` snippet that does not
spread its props ([SZ001](/docs/v9/core/errors#sz001)), a trigger without an
accessible name ([SZ002](/docs/v9/core/errors#sz002)) and a trigger outside a
`List` ([SZ003](/docs/v9/core/errors#sz003)).
