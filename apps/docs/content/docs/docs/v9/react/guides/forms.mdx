---
title: Forms
description: Two ways to connect a form to a step.
---

A step's data is the committed value of its form. There are two ways to get it
there, and you can mix them in one flow.

## Let the step validate

Give the step a schema and pass the form values to `next`. This needs no form
library.

```tsx
const signup = defineStepper([
  { id: "account", schema: z.object({ email: z.string().email() }) },
  { id: "done" },
]);

function AccountStep() {
  const stepper = signup.useStepperContext();
  const issues = stepper.issues();

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        stepper.next(Object.fromEntries(new FormData(event.currentTarget)));
      }}
    >
      <input name="email" defaultValue={stepper.data.account?.email} aria-invalid={!!issues} />
      {issues?.map((issue) => <p key={issue.message}>{issue.message}</p>)}
      <button type="submit">Continue</button>
    </form>
  );
}
```

`defaultValue` reads the stored data, so the field is filled when the person
comes back to the step, including after a rejected `next()`.

## Let the form library validate

When a library such as React Hook Form or TanStack Form already validates the
fields, call `next` from its submit handler. You can keep the schema on the
step as well: it types the data and guards against a form that forgot a field.

```tsx
function AccountStep() {
  const stepper = signup.useStepperContext();
  const form = useForm({
    resolver: zodResolver(accountSchema),
    defaultValues: stepper.data.account,
  });

  return (
    <form onSubmit={form.handleSubmit((values) => stepper.next(values))}>
      <input {...form.register("email")} />
      <button type="submit">Continue</button>
    </form>
  );
}
```

## Field errors from the step

Issues carry a `path`, so they map onto fields:

```tsx
const result = await stepper.next(values);
if (!result.accepted && result.issues) {
  for (const issue of result.issues) {
    const name = issue.path?.map((part) => (typeof part === "object" ? part.key : part)).join(".");
    if (name) form.setError(name, { message: issue.message });
  }
}
```

## Keeping what was typed

A step that unmounts loses its local form state. Three options, from simplest:

- Read `stepper.data` as default values, as above. Data is saved by `next()`,
  also when validation fails.
- Save drafts while typing with `stepper.setData("account", values)`.
- Keep every panel mounted with `forceMount` on
  [`Stepper.Content`](/docs/v9/react/api/primitives#content).

## Submitting everything

`onFinish` receives the data of every step when the last one is completed.

```tsx
<signup.Provider onFinish={(data) => api.createAccount(data)}>
```
