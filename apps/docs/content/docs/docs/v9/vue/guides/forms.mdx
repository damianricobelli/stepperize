title: Forms
description: Collect each step's data with v-model, validate it with a schema, and submit at the end.
---

Stepperize owns the flow; your fields stay in `v-model` or in your form
library. The two meet in one call: `next(data)`.

## A schema per step

Give a step a `schema` and its data is typed and validated. Any
[Standard Schema](https://standardschema.dev) library works.

```ts title="signup.ts"
import { defineStepper } from "@stepperize/vue";
import { z } from "zod";

export const signup = defineStepper([
  { id: "account", title: "Account", schema: z.object({ email: z.email() }) },
  { id: "profile", title: "Profile", schema: z.object({ name: z.string().min(1) }) },
  { id: "done", title: "Done" },
]);
```

## Validate on Continue

`next(data)` saves the data for the current step, validates it and only moves
when it is valid. It resolves with what happened, and `stepper.issues()` holds
the reasons until the data changes.

```vue title="Signup.vue"
<script setup lang="ts">
import { reactive } from "vue";
import { signup } from "./signup";

const stepper = signup.useStepper({
  onFinish: (output) => createAccount(output),
});

const account = reactive({ email: "" });
const profile = reactive({ name: "" });

function submit() {
  if (stepper.current.id === "account") return stepper.next({ ...account });
  if (stepper.current.id === "profile") return stepper.next({ ...profile });
  return stepper.next();
}
</script>

<template>
  <form @submit.prevent="submit">
    <label v-if="stepper.current.id === 'account'">
      Email
      <input v-model="account.email" type="email" />
    </label>
    <label v-else-if="stepper.current.id === 'profile'">
      Name
      <input v-model="profile.name" />
    </label>
    <p v-else>All set, {{ stepper.output.profile?.name }}.</p>

    <p v-for="issue in stepper.issues()" :key="issue.message" role="alert">
      {{ issue.message }}
    </p>

    <button type="button" :disabled="stepper.isFirst" @click="stepper.prev()">Back</button>
    <button type="submit" :disabled="stepper.isPending">
      {{ stepper.isLast ? "Create account" : "Continue" }}
    </button>
  </form>
</template>
```

- `stepper.data` is what each step holds as it was typed; `stepper.output` is
  what each schema produced, with transforms and defaults applied.
- `onFinish(output, data)` runs once, when `next()` completes the last step.
  Return a promise and `stepper.isPending` stays `true` until it settles.

## Keeping drafts

To keep what was typed when the user goes back, or to persist it, write the
draft as it changes and read it back when the step mounts:

```vue title="AccountStep.vue"
<script setup lang="ts">
import { reactive, watch } from "vue";
import { signup } from "./signup";

const stepper = signup.useStepperContext();
const values = reactive({ email: "", ...stepper.data.account });

watch(values, () => stepper.setData("account", { ...values }));
</script>
```

`setData` does not validate. A step that was complete stops being complete when
its data changes.

## Checking one step without moving

`stepper.validate()` checks the current step and resolves with its issues, or
`undefined` when it is valid. Use it for "validate on blur".
